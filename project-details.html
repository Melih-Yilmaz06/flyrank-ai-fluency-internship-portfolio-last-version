Featured Project

Şefim Temiz

3rd Place — Engineering Real-Time Detection Computer Vision

About the Project

Şefim Temiz is an award-winning real-time hygiene violation detection system that earned 3rd place in the Engineering category. The core idea was simple but ambitious: take computer vision out of the research notebook and deploy it where it actually matters — in a live, production environment.

The system uses a live camera feed to continuously monitor a workspace for hygiene violations such as missing gloves, missing hairnets, and missing masks. When a violation is detected, it's logged instantly with a timestamp, violation type, and a captured frame for review.

The dashboard — Şefim Temiz PRO — provides a complete operational view: total violations for the day, active camera count, the most frequent violation type, a distribution chart, and a scrollable log of recent detections. Everything runs in real time with minimal latency.

Why It Matters

Most computer vision projects live and die in Jupyter notebooks. This project was built to prove that a well-engineered pipeline can run reliably in the real world — handling noisy camera feeds, varying lighting conditions, and continuous operation without crashing. It's not just a model; it's a system.
